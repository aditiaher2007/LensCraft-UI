# LensCraft-UI
A website landing page built using HTML and CSS.

## About the Project

LenseCraft UI is a frontend mini project that focuses on creating a clean and attractive eyewear website layout.

The project demonstrates the use of HTML for structuring the webpage and CSS for styling and designing the user interface.


##  Technologies Used

- HTML5
- CSS3
